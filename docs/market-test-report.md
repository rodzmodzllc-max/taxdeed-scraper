Rules (`harvesters/sources/market_metrics.py`), no score:

* **HELD** - no customer-visible record (the source is not cleared for customers). Kept for admins.
* **NOT_CURRENT** - visible, but the inventory is a finished sale.
* **FOCUS** - visible and every rule holds: identity >= 95%, coordinates >= 75%, published path >= 80% (auction URL for auctions; the certificate sale page or acquisition evidence for liens; verified acquisition evidence for Available), and no freshness / dated-list / source-review caveat.
* **BROWSE** - visible, at least one rule fails (named below).

Shortlist order: FOCUS by visible records, then BROWSE by number of failed rules and visible records. Raw size never promotes a market past a failed rule; NOT_CURRENT and HELD markets are not prioritized.

Percentages are of active records. Imagery-capable = coordinates (the live USDA NAIP view needs nothing else). Activation is NOT implied by any list here.
